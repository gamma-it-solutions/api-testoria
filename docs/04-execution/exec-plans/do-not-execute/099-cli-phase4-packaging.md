### Build commands

```bash
cd cli/
python -m build          # produces dist/testoria_cli-1.0.0.tar.gz + .whl
twine check dist/*       # validate metadata before upload
twine upload dist/*      # upload to PyPI (requires ~/.pypirc or TWINE_* env vars)
```

### GitHub Actions workflow

```yaml
# .github/workflows/publish-cli.yml
name: Publish CLI to PyPI

on:
  push:
    tags:
      - "cli/v*"

jobs:
  publish:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: cli/
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: pip install build twine
      - run: python -m build
      - run: twine check dist/*
      - run: twine upload dist/*
        env:
          TWINE_USERNAME: __token__
          TWINE_PASSWORD: ${{ secrets.PYPI_API_TOKEN }}
```

### `cli/README.md` structure

```markdown
# Testoria CLI

## Installation
pip install testoria-cli

## Quick start
testoria login --url https://testoria.example.com
testoria project list
testoria run create --project-id 1 --name "Sprint 42"
testoria result submit --run-id 7 --case-id 3 --status passed

## pytest integration
pytest --testoria-run-id=42 --testoria-case-map=case_map.json

## Commands reference
(auto-generated by `testoria --help`)
```

### Version bumping process

1. Update `version` in `pyproject.toml`
2. Add entry to `CHANGELOG.md`
3. Commit: `git commit -m "cli: bump to 1.x.x"`
4. Tag: `git tag cli/v1.x.x`
5. Push tag → GitHub Actions publishes automatically
